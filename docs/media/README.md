# README media

`overview.svg` is an editable workflow diagram based on the checked-in project. It contains no external image or font requests. Text alternatives are included in the main README.

`filter.gif` and `filter.png` render synthetic log lines passed through the real `filterLinesByLevel` export in `src/logLevel.ts`. They illustrate filtering behavior; they are not VS Code screenshots. Frames: ALL, WARNING, ERROR, ERROR with one context line. Each frame remains visible for 2.3 seconds.
